
run this in solution directory:
dotnet ef dbcontext scaffold "Name=DefaultConnection" Microsoft.EntityFrameworkCore.SqlServer -o Entities --project Test.Model --startup-project Test.Web -f

Scaffold-DbContext "Name=DefaultConnection" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Entities -Project Test.Model -StartupProject Test.Web -Force

oracle:
Scaffold-DbContext "User Id=test;Password=test;Data Source=localhost:1521/XEPDB1" Oracle.EntityFrameworkCore -OutputDir Entities -Project Oracle.Model -StartupProject Test.Web -Force

Scaffold-DbContext "Name=ReportDbConnection" Oracle.EntityFrameworkCore -OutputDir Entities -Project Oracle.Model -StartupProject Test.Web -Force

install packages:
====================
for .net core 6
Install-Package Microsoft.EntityFrameworkCore.Tools
Install-Package Microsoft.EntityFrameworkCore.Design -Version 6.0.3
Install-Package Microsoft.EntityFrameworkCore.SqlServer -Version 6.0.3

for .net core 8
Install-Package Microsoft.EntityFrameworkCore.SqlServer -Version 8.0.11 or for oracle: Install-Package Oracle.EntityFrameworkCore -Version 8.23.40
Install-Package Microsoft.EntityFrameworkCore.Tools -Version 8.0.11
Install-Package Microsoft.EntityFrameworkCore.Design -Version 8.0.11
